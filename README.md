# House Bali Gateway

Crie uma landing page 100% mobile-first, estilo VSL moderna e de alta conversão.

Identidade visual:

- Fundo preto sólido (#000000)

- Cores de destaque: vermelho intenso (#FF1A1A e #CC0000)

- Tipografia limpa, bold e altamente legível no celular

- Visual premium, clean e sofisticado

- Use a logo “House Bali Oficial” centralizada no topo

Estrutura da página (somente estes elementos):

1. Headline principal (grande e impactante):

“Acesso Exclusivo Liberado: Entre Agora na Área Privada House Bali”

2. Subheadline:

“Conteúdo premium + acesso direto aos membros. Vagas limitadas.”

3. Player de vídeo:

- Ocupa a maior parte da tela no mobile

- Autoplay com áudio ligado

- Controles de progresso e seek completamente desabilitados (o usuário não pode avançar ou voltar o vídeo)

- Sem barra de tempo visível

- Experiência de vídeo “preso” (o usuário precisa assistir)

4. Após 60 segundos de vídeo:

- Aparece automaticamente um botão grande e chamativo

- Texto do botão: “QUERO MEU ACESSO AGORA”

- Botão vermelho forte com leve animação de destaque (pulse)

- Ao clicar, redireciona para o checkout

5. Texto de urgência abaixo do botão:

“Oferta por tempo limitado. Esta página pode ser removida a qualquer momento.”

Regras importantes:

- Página extremamente limpa (sem menu, sem rodapé, sem links extras)

- 100% focada no vídeo + botão de ação

- Design full mobile (prioridade total para celular)

- Carregamento rápido e visual premium
